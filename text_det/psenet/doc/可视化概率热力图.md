你的理解基本正确。在你当前的 PSENet 实现中，ResNet18 + FPN 最终输出 3 张概率图，分别预测 3 个不同大小的文本区域（Kernel）。

但要注意：模型本身并不直接预测文本框。它预测的是像素级文本区域，之后通过 PSE（Progressive Scale Expansion，渐进式尺度扩张）算法，将这些区域转换成独立的文本实例，最后计算每个实例的外接框。

整个过程可以理解为：

输入图像（例如 1024×1024）

ResNet18 + FPN + Prediction Head

K1 最小核

Sigmoid → 阈值

K2 中间核

Sigmoid → 阈值

K3 完整文本区

Sigmoid → 阈值

PSE：从 K1 逐步扩张到 K2、K3

文本实例 → Polygon → 最小外接矩形

这里最关键的是：K1、K2、K3 不是三个不同的文本类别，而是同一段文字在不同收缩尺度下的区域预测。

## 二、三张概率图是如何生成的？

你当前的 `model.py` 最后一层是：

```
nn.Conv2d(fpn_channels, num_kernels, kernel_size=1)
```

默认 `num_kernels=3`。

假设输入图片经过 Letterbox 后是 `1024×1024`：

```
logits = model(image)# shape: [1, 3, 1024, 1024]probs = logits.sigmoid()# shape: [1, 3, 1024, 1024]
```

这里需要区分：

- `logits`：神经网络的原始输出，可以是任意实数。
- `sigmoid()`：将其映射到 0–1，作为每个像素属于对应 Kernel 的预测概率。

三个通道的含义由训练时的标签决定：

| 通道 | 标签收缩比例 | 含义     |
| -- | ------ | ------ |
| K1 | 0.50   | 最小文本核  |
| K2 | 0.75   | 中间文本核  |
| K3 | 1.00   | 完整文本区域 |

注意这里使用的是 Sigmoid，而不是 Softmax。

因为一个像素可以同时属于 K1、K2、K3。它们不是互斥类别，而是嵌套的文本区域。

## 三、每个 Kernel 是否通过阈值确定前景和背景？

是的。你的 `pse.py` 中：

```
masks = probs >= threshold
```

默认：

```
threshold = 0.5
```

因此三个通道都使用相同的阈值。

例如，对于某个像素：

| Kernel | 概率   | 二值结果 |
| ------ | ---- | ---- |
| K1     | 0.82 | 1    |
| K2     | 0.91 | 1    |
| K3     | 0.98 | 1    |

如果某个像素的 K1 概率只有 0.3，而 K2=0.8、K3=0.9，那么其二值结果就是 `(0, 1, 1)`。

### 一个重要细节：强制嵌套

理论上应该满足：

\\[ K_1 \subseteq K_2 \subseteq K_3 \\]

但三个输出通道是独立预测的，不一定天然满足这个条件。

因此你的代码还执行：

```
for k in range(masks.shape[0] - 2, -1, -1):    masks[k] &= masks[k + 1]
```

它确保小 Kernel 一定包含在大 Kernel 内。

这是正确而且很有必要的处理。

## 四、如何从三个 Kernel 得到文本框？

这才是 PSENet 最核心的部分。

假设一张图片包含两个非常接近的单词：`HELLO` 和 `WORLD`。

示意：两个相邻文字实例逐渐收缩

概念示意：K3 的两个区域可能连接，K1 的两个核心则更容易分开。实际预测的是像素 Mask，不是上图的矩形。

### 第一步：从 K1 找出独立文本种子

使用 OpenCV 连通域分析：

```
count, labels, stats, _ = cv2.connectedComponentsWithStats(    masks[0].astype(np.uint8),    connectivity=4)
```

假设得到两个连通区域：

- ID=1：HELLO 的中心区域
- ID=2：WORLD 的中心区域

这里不需要知道文字内容，只需要知道它们是两个独立区域。

面积小于 `min_kernel_area`（默认 5 像素）的种子会被删除。

### 第二步：从 K1 扩张到 K2

对于 K1 中每个已经有 ID 的像素，检查它的上下左右四个相邻像素。

如果相邻像素满足：

1. 属于 K2 的前景。
2. 尚未被其他实例占用。

那么就把当前实例的 ID 赋给该像素，并将它加入 BFS 队列。

不断重复，直到无法继续扩张。

### 第三步：从 K2 扩张到 K3

继续执行相同过程，只是这次允许扩张的区域变成 K3。

PSE 逐级扩张的过程

K1 种子

扩张至 K2

扩张至 K3

绿色和蓝色代表两个文本实例的 ID。扩张只增加实例像素，不重新创建实例。

这一步最重要的规则：

当两个文本实例同时向同一个像素扩张时，谁先通过 BFS 到达，谁就占有这个像素。

因此，即使 K3 中两个单词粘连成一个大区域，PSE 也有机会将它们分开。

但如果两个单词在 K1 阶段已经连成了一个连通域，PSE 通常就无法再把它们拆开。

这也是 PSENet 特别重视最小文本核的原因。

## 五、从文本实例生成最终文本框

经过 PSE 后，得到的不是概率图，而是一张实例 ID 图（Instance Label Map）：

```
0 = 背景
1 = 第一个文本实例
2 = 第二个文本实例
3 = 第三个文本实例
...
```

之后你的 `extract_instances()` 会执行以下操作：

1\. 过滤过小的实例

```
if area < min_area:    continue
```

默认 `min_area=30`。

2\. 计算文本实例的置信度

```
score = float(score_map[component].mean())
```

这里 `score_map` 是 K3 的概率图。

也就是说，取实例内所有像素的 K3 预测概率的平均值。

如果 `score < min_score`（默认 0.5），丢弃该实例。

3\. 提取轮廓

```
contours, _ = cv2.findContours(...)
```

4\. 生成旋转矩形框

```
box = cv2.boxPoints(    cv2.minAreaRect(contour))
```

这样得到四个顶点：

```
[    [x1, y1],    [x2, y2],    [x3, y3],    [x4, y4]]
```

最后再通过 `to_original()` 将 Letterbox 画布上的坐标映射回原图坐标。

于是，你就得到了最终的文本检测框。

## 七、PSENet 最值得理解的三个问题

1. 为什么不直接使用 K3？ 因为相邻文字可能粘连，直接对 K3 做连通域分析，会把多个文本实例当成一个。
2. 为什么需要 K1？ K1 尽可能让不同文字分开，提供独立的实例种子；代价是小文字可能在收缩时消失。
3. 为什么需要 K2？能不能直接从 K1 扩张到 K3？ 可以尝试，但中间尺度能对扩张过程施加更细的约束，减少相邻文本发生错误归属的机会。它是 PSENet 渐进式扩张思想的重要部分。

最后，有一个很适合你当前项目的学习实验：对同一张图片分别绘制三张原始概率热力图、三张二值 Mask、三个阶段的 PSE 实例 ID 图，以及最终文本框。

你的 `predict.py` 已经有二值 Mask 和 PSE 阶段的可视化，唯独缺少原始的概率热力图。把它补上，就可以直观地看到：网络预测了什么、阈值删除了什么、PSE 又如何把像素组织成独立文字实例。

这会比继续训练模型更有助于真正掌握 PSENet。
